# A 股量化交易系统

面向个人 A 股投资者（资金 50-100 万）的量化交易软件，基于 Python + Streamlit 构建，数据源使用免费的 AKShare。

## 功能概览

| 模块 | 功能 |
|------|------|
| 📊 市场总览 | 大盘指数 K 线、自选股实时行情 |
| 🗄️ 数据管理 | 下载/缓存 A 股历史 K 线（SQLite） |
| 🔬 策略回测 | 10 种内置策略、向量化回测、绩效分析 |
| 📈 策略信号 | 实时查看策略信号与指标叠加图 |
| 🎯 多因子选股 | 动量/波动率/RSI/均线多因子评分排名 |
| 💼 模拟账户 | 纸上交易（含 T+1/手续费/涨跌停规则） |
| 🛡️ 风控设置 | 仓位上限、止损止盈、回撤熔断 |

## 内置策略

**趋势跟踪**
- MA 金叉死叉（可选 SMA/EMA，自定义快慢周期）
- MACD 策略（柱状图金叉死叉）
- 布林带突破
- 三均线多头排列

**均值回归**
- RSI 超买超卖
- 布林带均值回归
- 均线偏离回归

**量价策略**
- 放量突破（价格 + 成交量双重确认）
- 价量背离（顶背离/底背离）
- 缩量回调买点

## 快速开始

### 1. 安装依赖

```bash
cd quant_trading
pip install -r requirements.txt
```

### 2. 启动应用

```bash
streamlit run app.py
```

浏览器访问 `http://localhost:8501`

### 3. 使用流程

1. **数据管理**：先下载需要的股票历史数据（会自动缓存到本地 SQLite）
2. **策略回测**：选择策略和参数，运行回测查看 Sharpe/回撤等指标
3. **策略信号**：查看策略对个股的最新信号
4. **多因子选股**：对股票池进行量化评分，筛选候选标的
5. **模拟账户**：用纸上交易验证策略，无需真实资金
6. **风控设置**：配置止损止盈和回撤熔断参数

## A 股特殊规则

本系统已内置 A 股交易规则：

- **T+1**：当日买入，次日才能卖出
- **手续费**：买入 0.025% + 卖出 0.025% + 印花税 0.1%（仅卖出）
- **最小交易单位**：100 股（1 手）
- **涨跌停限制**：普通股 ±10%，科创板/创业板注册制 ±20%

## 项目结构

```
├── app.py                    # Streamlit 入口
├── requirements.txt
├── config.yaml               # 全局配置
├── core/
│   ├── data/                 # AKShare 封装 + SQLite 缓存
│   ├── indicators.py         # MA/MACD/RSI/布林带等技术指标
│   ├── strategies/           # 10 种内置策略
│   ├── backtest/             # 向量化回测引擎 + 绩效指标
│   ├── risk/                 # 风险管理器
│   └── trading/              # 模拟账户 + 抽象券商接口
└── pages/                    # Streamlit 多页面
```
